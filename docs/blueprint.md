# **App Name**: Clancig CV

## Core Features:

- Personal Info Display: Display personal information, including name, title, summary, photo, and contact details.
- Work Experience Timeline: Show work experience with company, position, period, description, technologies, and achievements.
- Education and Courses Grid: List education courses with title, platform, year, status, and technologies.
- Skills Visualization: Present technical skills grouped by category with visual skill level indicators.
- Dark Mode Toggle: Implement a toggle switch for users to switch between light and dark themes for comfortable viewing.
- Automatic Language Detection: Automatically detect user's preferred language and provide support for Spanish, English, and Portuguese using next-i18next.

## Style Guidelines:

- Primary color: Dark Blue (#2c3e50) to convey professionalism and trust.
- Background color: Light gray (#f0f2f5), subtly desaturated from the primary hue, provides a clean, modern backdrop.
- Accent color: Teal (#3498db), analogous to the primary but with distinct brightness and saturation, highlights interactive elements and CTAs.
- Headline font: 'Space Grotesk', sans-serif, headlines and short body; body: 'Inter', modern and neutral
- Use Heroicons for a consistent, modern, and professional look.
- Employ a clean, modern layout with a focus on readability and user experience, ensuring responsiveness across devices.
- Incorporate subtle animations using Framer Motion to enhance user engagement without being distracting.
